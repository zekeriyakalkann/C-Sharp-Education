- **C# Fundamentals:** Variables, operators, conditional statements and basic programming concepts.
- **Algorithms:** Bubble Sort, Selection Sort and other sorting algorithms.

- **Data Structures:** Stack, Queue, Linked List, Dictionary and Binary Trees.

- **Framework:** .NET Framework / .NET
